# Unpublished legacy source

`legacy/` preserves the previous site’s tracked theme, articles, CV, configuration, and images before the rebuild. Referenced images for the three curated projects were copied into `assets/projects/`.

This entire folder is excluded from Jekyll output. It must never be added to the homepage, navigation, gallery, sitemap, or Jekyll `include` configuration. Repository files are still visible to anyone with repository access; this archive is not private storage.

The pre-existing untracked Blackjack file was left in its original location under `blog/_posts/`. That folder is also excluded from the published site.
